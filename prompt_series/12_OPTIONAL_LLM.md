# Optional LLM context assistant
Core app must work completely without LLM. Implement disabled-by-default server-side interface for an approved OpenAI-compatible endpoint only; no credentials committed, no client secret, no external data by default. Optional context assistance: explain capture problems, read approved supplied instructions, summarize diagnostic results, help navigate configuration. LLM never computes geometry, decides acceptance, changes tolerances, invents coordinates or overrides gates. Require structured responses and validate against schemas, treat OCR/doc content as untrusted data, quote provenance. Mock adapter and opt-in integration test, do not call real API in public development. Document how an authorized enterprise administrator can configure endpoint and retention separately.
