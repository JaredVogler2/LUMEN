# Post-installation verification
Capture an independent photograph or video frame with references still fixed; re-register, identify actual placard perimeter using contour/edge proposals and manual confirmation, transform measured corners into local frame. Compare to target coordinates and report signed center/edge deviations, rotation, width/height discrepancy and uncertainty. Handle hidden corners, glare, curled stickers, partial placement, marker movement and registration loss. Distinguish measurement evidence from formal acceptance; output observed deviations and research-only status. Export generic session summary with coordinate semantics, image annotations, tag/calibration/config revisions, quality flags and algorithm version. Avoid retaining photos by default; explicit export/delete. Test known translations/rotation and invalid evidence.
