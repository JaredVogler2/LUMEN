# Floor and curved edge registration
Use calibrated/rectified images and shared geometry to propose floor-panel interface, side boundary, curve axis and origin. Distinguish occlusion silhouette, physical seam, lighting gradient and actual tangent transition. Use edge gradients, line segments, robust fitting, multiple views and operator review. Do not assume curvature axis universally parallel to engineering vertical or floor seam universally orthogonal; only use these axes when operation definition establishes relationship. A uniform cylindrical edge can establish direction but not absolute translation along it. Floor interface can supply second constraint if identifiable and correct; two valid nonparallel references establish local origin. Sign and reference semantics explicitly configured.
Fit local plane and where observable a sparse cylindrical/profile model. Distinguish projected-axis offsets from surface arc lengths. Compare raw axis disagreement to configured engineering limits; orthogonalize only if justified, preserve original residuals. If datum off target plane, require 3D geometry or defined offset. If target itself curved, experimental mode only until validated. Provide manual confirmed baseline and visual evidence; never let manual edits override metrology gates. Test floor trims, gaps, tapered/inclined panels, different curve radii, false seams, symmetric geometry, missing floor, partial visibility and multiple competing solutions.
