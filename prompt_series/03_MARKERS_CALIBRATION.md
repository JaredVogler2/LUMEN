# AprilTags and metric camera calibration
Use OpenCV DICT_APRILTAG_36h11 or validated AprilTag detector. Support commercially preprinted 50 mm tags, any vendor, optional per-ID measured dimensions. Define detection-edge convention, distinguish sticker perimeter and quiet zone. IDs can repeat across sessions not within a scene. Detect corners at subpixel resolution, reject clipped, warped, ambiguous or tiny markers. Record corner residual and quality. No need to orient tags with floor.
Implement camera calibration using measured checkerboard/ChArUco target and diverse views; store resolution/lens and distortion, reject mismatched camera configurations. Document that web APIs do not provide calibrated intrinsics. Support homography on planar target even without complete 3D calibration when distortion is characterized and planar assumptions validated. Use solvePnP/IPPE square as applicable, handle pose ambiguity and cheirality. Verify measurements against independent reference, not nominal printer dimensions. Tests for rotated and different IDs, scaling, noise, lens distortion, duplicate IDs, glare and missing corners.
