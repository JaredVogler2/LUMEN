# Planar measurement baseline
Create functional single-photo measurement using a known square marker on same planar region as target. Undistort where calibrated; compute metric homography from four corners and refine with multiple observed correspondences only when coplanarity is supported. For independently placed tags, map their corners via initial homography, estimate their independent in-plane poses, compare measured dimensions and cross-validate rather than assuming known inter-tag spacing. Reject noncoplanar or bent tags, excessive extrapolation or unstable fits. One tag can determine planar mapping, prefer 2–4 for redundancy.
Operator selects actual floor boundary and physical side datum on rectified image. Confirm semantics and signed axes; intersect lines for local origin only when valid. Off-plane curvature cannot be projected into plane as if coplanar. Require configuration-defined offset or valid 3D evidence. Use explicit offsets and units; calculate rectangle corners from x,z,width,height,angle and reference point (center/corner). Round-trip overlay to original image, show metric grid and dimensions. Tests with independently rendered perspective, distortion and incorrect reference cases. First milestone: real photo import and measurable overlay on synthetic flat test panel.
