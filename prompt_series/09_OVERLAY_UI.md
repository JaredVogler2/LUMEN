# Polished touch-first placement workflow
Design professional industrial interface with large glove-friendly controls, high contrast, dark and light modes, accessible labels, clear acquisition cues. Screen sequence: identify/configure, marker check, capture sweep/photo review, datum review, rectified view, placement, verify. Render real image-space target polygon and metric grid using calibrated transforms; never use decorative fake grid for measurement. Include pan/zoom, original photo, rectified orthographic view, selectable origin and axis evidence, dimensions and rotation. For live video, only draw after current frame pose acquired, transform into displayed video coordinates and hide promptly on lost tracking; if performance inadequate use frozen image or deliberate capture. Mark frozen images clearly so user cannot mistake them for live placement. Consider phone stand or second operator, no required hardware.
Show actionable states: missing tag, move left/up/back, floor missing, ambiguous curve, poor quality, no valid guidance. Show diagnostic view of raw image and annotated geometry. Display research-only watermark, no production acceptance. Build functional sample session using generated assets, separate from real mode. Test mobile portrait/landscape, accessibility and pixel mapping.
