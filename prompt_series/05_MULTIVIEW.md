# Multi-view camera localization
Support arbitrary stationary tag placements with unknown relative poses. Build marker-camera observation graph, choose gauge (one known-size tag), estimate camera and tag poses using shared observations and calibrated intrinsics, handle planar pose ambiguity. Joint bundle adjustment with robust reprojection residuals, SE(3) updates, metric tag constraints, positive depth. Require connected graph, enough diverse viewpoints and overlap, check conditioning and held-out observations; reject moved markers and ambiguous solutions. No assuming markers are all coplanar unless proven/declared and tested. Estimate target plane from valid references and quantify residuals.
Triangulate stable feature observations only, not moving shadows. Use sparse geometry not mandatory dense photogrammetry. Video frame selection should optimize pose diversity, not frame count. Implement tracking loss and relocalization; hide live overlay when stale. Tests for unknown tag transforms, camera rolls, occlusion, graph disconnects, moving tag, narrow baseline, wrong tag size, inconsistent plane and scale. Compare multi-view vs single-view accuracy against ground truth.
