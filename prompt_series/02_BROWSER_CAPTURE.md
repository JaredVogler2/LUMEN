# Mobile camera, photo and video
Implement real iPhone Safari camera using getUserMedia environment-facing, no audio, playsinline, explicit permission and gesture. Support photo upload including multiple images and video upload or live sweep with frame extraction, orientation normalization, native pixel size and crop/display mapping. Use deterministic frame selection based on marker visibility, overlap, blur, exposure, and diversity; let user review, remove and retake. Start 3–9 views, request floor seam and curved side edge plus overlapping markers. Preserve images used in calibration.
Probe torch using getCapabilities/getSettings/applyConstraints; show control only when supported or verified. Report unknown torch state honestly. If unavailable, allow standard captures and externally taken flash images. On/off pairs ideally same viewpoint; align and reject incompatible exposure/motion. No assumption Safari exposes intrinsics/RAW/exposure lock. Use stable lens, zoom and resolution where possible. Camera stop on exit; permission/interruption recovery, timeout and upload progress. Browser tests for display transforms, file upload and UI states; actual managed iPhone/Posit test checklist separate from simulated tests.
