# App foundation
Build runnable FastAPI app with static HTML/CSS/JS or locally compiled TypeScript, Python vision modules, schemas, config, fixtures, pytest and browser tests. Keep one origin and support reverse-proxy subpaths. Pin Python and dependencies compatible with target Posit Connect; verify OpenCV headless includes aruco AprilTag dictionary. Avoid mandatory GPU, Node runtime, internet or CDN. Include local run instructions and dependency health check.
Define Session, Frame (pixel geometry, orientation, camera/lens/resolution, capture metadata), Calibration, MarkerObservation (ID, corners, measured size), Pose, DatumObservation, LocalFrame, SurfaceModel, PlacementSpec, Uncertainty, Verification, status enum. Keep capture, recognition, geometry, policy and overlays separate. Design API endpoints for session/capture, calibration, analysis, overlay, export and delete. Bound image sizes and sessions; no external telemetry. Synthetic sample operation and clear demo mode. Tests for schemas, unit conversions, errors and paths.
