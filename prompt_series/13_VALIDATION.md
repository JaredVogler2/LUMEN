# Synthetic and physical test program
Build deterministic synthetic renderer of generic flat and rounded panels, known marker dimensions and arbitrary poses, seams, placard positions, camera distortions, flash lighting, glare, blur, noise, exposure shifts and occlusion. Hold out configurations from tuning. Unit, integration, browser and end-to-end tests. Report translation, angular and corner error, false registration acceptance, coverage, latency and failure rate; compare single-view/manual vs automatic multi-view vs illumination. Include negative cases: no scale, moved tags, wrong IDs/dimensions, symmetry, missing origin, nonorthogonal axes, off-plane target and low contrast. Do not manufacture empirical results.
Provide physical test protocol using nonproduction curved/flat panels, measured 50 mm commercial tags, independently measured targets and datum directions. Vary distance, roll, lighting, curvature and operators; repeated independent captures, gauge R&R or comparable repeatability/reproducibility analysis, error budget. Test real managed iPhone browser and actual Posit environment separately; mark NOT RUN if unavailable. Record sample size, measurement instrument, raw data, thresholds chosen from actual engineering needs (not claimed production limits).
