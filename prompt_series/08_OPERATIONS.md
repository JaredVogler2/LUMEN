# Placard operation definitions
Build editable local generic operation library (JSON/CSV or approved persistent database adapter) with panel/placard ID, effectivity/config, datum names and signs, placement offset units, axis/surface semantics, reference point, width/height/rotation, authorized tolerances, revision and provenance. No real company records. Support manual entry and camera barcode scan (ZXing or tested alternative), OCR optional for text identification, verify exact match and ask operator on ambiguity. Never derive physical scale from barcode unless actual measured dimensions configured. Do not invent placement requirements; missing tolerance or datum prevents validated status. Version configurations and record session snapshot. Support multiple placards on same registered panel, switch target without reinitializing while references remain valid. Tests for unit conversion, ambiguous ID, revision, incomplete records, wrong part and invalid dimensions.
